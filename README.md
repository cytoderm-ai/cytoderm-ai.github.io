# Cytoderm AI 项目展示页面

基于 Vue3 + Vite 的模块化研究项目展示网站。

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 📁 目录结构

```
├── public/             # 静态资源（图片、视频等）
│   └── chunkflow/      # ChunkFlow 项目资源
├── src/
│   ├── index.js        # 路由配置
│   ├── main.js         # 应用入口
│   └── chunkflow/      # ChunkFlow 项目源码
│       └── components/ # Vue 组件
├── index.html
├── vite.config.js
└── package.json
```

## ➕ 添加新项目

1. 创建 `src/your-project/` 和 `public/your-project/` 文件夹
2. 在 `src/index.js` 中注册路由
3. 在 `src/main.js` 中配置页面标题
